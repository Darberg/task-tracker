# 📝 Task Tracker (Go CLI)

A simple command-line Task Tracker built with Go.  
It supports creating, listing, updating, deleting, and paginating tasks stored in a JSON file.

---

## 🚀 Features

- Add new tasks
- List all tasks
- Update task status
- Delete tasks by ID
- Paginated task listing
- JSON file persistence
- Simple CLI menu system
